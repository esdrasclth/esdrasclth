# Esdras Clother

**Software for operations teams** — warehouse, manufacturing, maintenance and logistics.
Founder of [BrandSofts](https://www.brandsofts.com/) · San Pedro Sula, Honduras 🇭🇳

I build business applications end to end: from the database to the screen the
operator uses on the shop floor. Most of my work is **TypeScript** — **Next.js**
and **NestJS** over **PostgreSQL** — plus **VB.NET / WPF** desktop tools that read
from **JD Edwards World (AS400)** when the data lives in the ERP.
